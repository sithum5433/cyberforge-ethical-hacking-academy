# CyberForge — Sri Lankan Ethical Hacking Academy

CyberForge is a self-paced cybersecurity learning reader built from the Sri Lankan Elite Hacker's Bible curriculum. It covers foundations, Linux, networking, web security, reconnaissance, penetration testing, privilege escalation, Active Directory, DFIR, DevSecOps, threat modeling, and hands-on labs.

## Open the academy

Open [`index.html`](./index.html) locally or visit the hosted GitHub Pages site.

## Included

- 21 curriculum volumes rendered as a searchable reader
- Progress tracking, saved chapters, notes, focus mode, and reading controls
- Markdown source chapters in [`chapters/`](./chapters/)
- PDF reference edition
- Static GitHub Pages deployment through `.github/workflows/pages.yml`

## Responsible use

Use the material only on systems you own or have explicit permission to test. Follow applicable law, responsible disclosure rules, and your organization's security policies.
